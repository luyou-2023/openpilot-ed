# OpenPilot 代码执行链路分析文档

## 文档说明

本文档详细分析OpenPilot从传感器数据采集到CAN消息发送的完整执行链路，重点关注：
- 函数调用关系
- 参数传递
- 返回值处理
- 数据流转过程

---

## 数据链路总览

```
摄像头 → camerad → VisionIPC → modeld → modelV2消息
底盘数据 → pandad → CAN消息 → card → carState消息
         ↓
    SubMaster订阅
         ↓
    controlsd → 状态机 → 控制计算 → carControl消息
         ↓
    card → CarInterface → CAN消息生成 → sendcan → pandad → CAN总线
```

## 链路1：摄像头数据采集链路

### 1.1 摄像头驱动启动

**文件**：`system/camerad/main.cc`

**入口函数**：
```cpp
int main(int argc, char *argv[]) {
  int ret = util::set_realtime_priority(53);  // 设置实时优先级
  ret = util::set_core_affinity({6});          // 绑定CPU核心
  camerad_thread();                             // 启动摄像头线程
  return 0;
}
```

**调用链**：
```
main() 
  → util::set_realtime_priority(53)
  → util::set_core_affinity({6})
  → camerad_thread()
```

**参数**：
- `priority = 53`：实时优先级
- `core = 6`：CPU核心编号

**返回值**：无（线程持续运行）

### 1.2 摄像头线程初始化

**文件**：`system/camerad/cameras/camera_common.h`

**函数调用**：
```cpp
void camerad_thread() {
  // 1. 初始化摄像头硬件
  cameras_init();
  
  // 2. 创建VisionIPC服务器
  VisionIpcServer vipc_server("camerad", VISION_STREAM_MAX, false);

  vipc_server.create_buffers(VISION_STREAM_WIDE_ROAD, 1, false, ...);
  vipc_server.create_buffers(VISION_STREAM_DRIVER, 1, false, ...);
  vipc_server.start_listener();
  
  // 3. 启动摄像头处理循环
  while (true) {
    // 采集图像
    // 处理图像
    // 发布到VisionIPC
  }
}
```

**关键调用**：
1. `cameras_init()` → 初始化摄像头硬件
2. `VisionIpcServer::create_buffers()` → 创建共享内存缓冲区
3. `VisionIpcServer::start_listener()` → 启动IPC服务器

**参数传递**：
- `stream_type`：流类型（ROAD/WIDE_ROAD/DRIVER）
- `num_buffers`：缓冲区数量
- `width, height`：图像尺寸

### 1.3 图像采集和处理

**文件**：`system/camerad/cameras/`（各品牌特定实现）

**调用流程**：

**参数**：

- `yuv_buf`：处理后的YUV缓冲区

### 2.2 CAN消息接收

**函数**：`can_recv_thread`

```python
def can_recv_thread(panda):
  while True:
    # 1. 从Panda接收CAN消息
    can_msgs = panda.can_recv()
    
    # 2. 转换为capnp格式
    can_list = []
    for msg in can_msgs:
      can_list.append({
        'address': msg[0],
        'dat': bytes(msg[2]),
        'src': msg[3],
        'busTime': msg[1]
      })
    
    # 3. 发布到消息队列
    can_send = messaging.new_message('can', len(can_list))
    can_send.can = can_list
    pm.send('can', can_send)
```

**数据流**：
```
CAN总线 
  → panda.can_recv() 
  → can_msgs (list)
  → 转换为capnp格式
  → messaging.new_message('can')
  → pm.send('can')
  → 消息队列
```

**参数**：
- `panda`：Panda设备对象
- `can_msgs`：原始CAN消息列表

**返回**：无（通过消息队列发布）

### 2.3 CAN消息订阅（card模块）

**文件**：`selfdrive/car/card.py`

**订阅流程**：
```python
class Car:
  def __init__(self, CI=None):
    # 1. 订阅CAN消息
    self.can_sock = messaging.sub_sock('can', timeout=20)
    
    # 2. 订阅其他消息

```

**接收流程**：
```python
def state_update(self) -> car.CarState:
  # 1. 从消息队列接收CAN消息
  can_strs = messaging.drain_sock_raw(self.can_sock, wait_for_one=True)
  
  # 2. 调用CarInterface更新状态
  CS = self.CI.update(self.CC_prev, can_strs)
  
  return CS
```

**调用链**：
```
messaging.drain_sock_raw('can')
  → 从消息队列读取
  → 返回can_strs (list[bytes])
  → self.CI.update(CC_prev, can_strs)
  → 返回CarState
```

**参数传递**：
- `self.can_sock`：CAN消息socket
- `wait_for_one=True`：等待至少一条消息
- `self.CC_prev`：上一次的控制命令
- `can_strs`：CAN消息字符串列表

**返回值**：
- `CS`：`car.CarState`对象，包含所有车辆状态

### 2.4 CarInterface状态解析

**文件**：`selfdrive/car/interfaces.py`

**update函数**：
```python
def update(self, c: car.CarControl, can_strings: list[bytes]) -> car.CarState:
  # 1. 转换CAN消息格式
  can_list = can_capnp_to_list(can_strings)
  
  # 2. 更新所有CAN解析器
  for cp in self.can_parsers:
    if cp is not None:
      cp.update_strings(can_list)
  
  # 3. 调用子类实现的状态更新
  ret = self._update(c)
  
  # 4. 设置有效性标志
  ret.canValid = all(cp.can_valid for cp in self.can_parsers if cp is not None)
  ret.canTimeout = any(cp.bus_timeout for cp in self.can_parsers if cp is not None)
  
  return ret
```

**调用链**：
```
update(c, can_strings)
  → can_capnp_to_list(can_strings)  # 格式转换
  → cp.update_strings(can_list)     # 更新解析器
  → self._update(c)                  # 子类实现（品牌特定）
  → 返回CarState
```

**参数**：
- `c`：`car.CarControl`，当前控制命令
- `can_strings`：CAN消息字符串列表

**返回值**：
- `ret`：`car.CarState`，解析后的车辆状态

**数据流**：
```
can_strings (list[bytes])
  → can_capnp_to_list()
  → can_list (list[dict])
  → cp.update_strings()  # 解析CAN消息
  → cp.vl  # 解析后的值字典
  → self._update()  # 提取状态
  → CarState对象
```

```python
def slice_outputs(self, model_outputs: np.ndarray) -> dict[str, np.ndarray]:
  # 根据元数据切片输出
  parsed_model_outputs = {
    k: model_outputs[np.newaxis, v] 
    for k, v in self.output_slices.items()
  }
  return parsed_model_outputs
```

**parse_outputs函数**：
```python
def parse_outputs(self, outs: dict[str, np.ndarray]) -> dict[str, np.ndarray]:
  # 1. 解析路径规划（MDN）
  self.parse_mdn('plan', outs, ...)
  
  # 2. 解析车道线（MDN）
  self.parse_mdn('lane_lines', outs, ...)
  
  # 3. 解析前车（MDN）
  self.parse_mdn('lead', outs, ...)
  
  # 4. 解析概率（sigmoid）
  self.parse_binary_crossentropy('lead_prob', outs)
  
  # 5. 解析期望状态（softmax）
  self.parse_categorical_crossentropy('desire_state', outs)
  
  return outs
```

```python
def fill_model_msg(base_msg, extended_msg, net_output_data, publish_state, ...):
  # 1. 填充路径规划
  position = modelV2.position
  fill_xyzt(position, ModelConstants.T_IDXS, 
            *net_output_data['plan'][0,:,Plan.POSITION].T,
            *net_output_data['plan_stds'][0,:,Plan.POSITION].T)
  
  velocity = modelV2.velocity
  fill_xyzt(velocity, ModelConstants.T_IDXS,
            *net_output_data['plan'][0,:,Plan.VELOCITY].T)
  
  acceleration = modelV2.acceleration
  fill_xyzt(acceleration, ModelConstants.T_IDXS,
            *net_output_data['plan'][0,:,Plan.ACCELERATION].T)
  
  # 2. 填充期望曲率
  action = modelV2.action
  action.desiredCurvature = float(net_output_data['desired_curvature'][0,0])
  
  # 3. 填充车道线
  modelV2.init('laneLines', 4)
  for i in range(4):
    lane_line = modelV2.laneLines[i]
    fill_xyzt(lane_line, PLAN_T_IDXS, np.array(ModelConstants.X_IDXS),
              net_output_data['lane_lines'][0,i,:,0],
              net_output_data['lane_lines'][0,i,:,1])
  
  # 4. 填充前车
  modelV2.init('leadsV3', 3)
  for i in range(3):
    lead = modelV2.leadsV3[i]
    fill_xyvat(lead, ModelConstants.LEAD_T_IDXS,
               *net_output_data['lead'][0,i].T,
               *net_output_data['lead_stds'][0,i].T)
    lead.prob = net_output_data['lead_prob'][0,i].tolist()
  
  # 5. 填充元数据
  meta = modelV2.meta
  meta.desireState = net_output_data['desire_state'][0].reshape(-1).tolist()
  meta.desirePrediction = net_output_data['desire_pred'][0].reshape(-1).tolist()
  meta.engagedProb = net_output_data['meta'][0,Meta.ENGAGED].item()
```

```python
@staticmethod
def parse_model(model_msg, model_error):
  if (len(model_msg.position.x) == ModelConstants.IDX_N and
      len(model_msg.velocity.x) == ModelConstants.IDX_N and
      len(model_msg.acceleration.x) == ModelConstants.IDX_N):
    
    # 1. 插值到MPC时间索引
    x = np.interp(T_IDXS_MPC, ModelConstants.T_IDXS, model_msg.position.x) - model_error * T_IDXS_MPC
    v = np.interp(T_IDXS_MPC, ModelConstants.T_IDXS, model_msg.velocity.x) - model_error
    a = np.interp(T_IDXS_MPC, ModelConstants.T_IDXS, model_msg.acceleration.x)
    j = np.zeros(len(T_IDXS_MPC))
  else:
    x = np.zeros(len(T_IDXS_MPC))
    v = np.zeros(len(T_IDXS_MPC))
    a = np.zeros(len(T_IDXS_MPC))
    j = np.zeros(len(T_IDXS_MPC))
  
  return x, v, a, j
```

**参数**：
- `model_msg`：`modelV2`消息对象
- `model_error`：模型速度误差

**返回值**：
- `x`：位置轨迹（MPC时间索引）
- `v`：速度轨迹
- `a`：加速度轨迹
- `j`：加加速度轨迹（初始为0）

**数据转换**：
```

  → x (12个点，MPC时间索引)
```

```python
def update(self, active, CS, VM, params, steer_limited, desired_curvature, llk):
  # 1. 从期望曲率计算期望转向角
  angle_steers_des_no_offset = math.degrees(
    VM.get_steer_from_curvature(-desired_curvature, CS.vEgo, params.roll)
  )
  angle_steers_des = angle_steers_des_no_offset + params.angleOffsetDeg
  
  # 2. 计算误差
  error = angle_steers_des - CS.steeringAngleDeg
  
  # 3. 计算前馈
  steer_feedforward = self.get_steer_feedforward(angle_steers_des_no_offset, CS.vEgo)
  
  # 4. PID控制
  output_steer = self.pid.update(
    error, 
    override=CS.steeringPressed,
    feedforward=steer_feedforward, 
    speed=CS.vEgo
  )
  
  return output_steer, angle_steers_des, pid_log
```

**参数**：
- `active`：是否激活
- `CS`：车辆状态
- `VM`：车辆模型
- `params`：实时参数
- `desired_curvature`：期望曲率（从modelV2获取）
- `llk`：定位信息

**返回值**：
- `output_steer`：输出转向（归一化到[-1, 1]）
- `angle_steers_des`：期望转向角（度）
- `pid_log`：PID调试信息
