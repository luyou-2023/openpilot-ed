### 1.3 manager_thread主循环

#### 1.3.1 初始化阶段

```python
def manager_thread() -> None:
  cloudlog.bind(daemon="manager")
  cloudlog.info("manager start")
  
  params = Params()
  
  # 确定要忽略的进程
  ignore: list[str] = []
  if params.get("DongleId", encoding='utf8') in (None, UNREGISTERED_DONGLE_ID):
    ignore += ["manage_athenad", "uploader"]
  if os.getenv("NOBOARD") is not None:
    ignore.append("pandad")
  ignore += [x for x in os.getenv("BLOCK", "").split(",") if len(x) > 0]
  
  # 订阅关键消息
  sm = messaging.SubMaster(['deviceState', 'carParams'], poll='deviceState')
  pm = messaging.PubMaster(['managerState'])
```

**关键点**：
- 根据环境变量和参数决定忽略哪些进程
- 订阅`deviceState`用于检测系统是否启动
- 订阅`carParams`用于获取车辆参数

#### 1.3.2 主循环执行

```python
write_onroad_params(False, params)
ensure_running(managed_processes.values(), False, params=params, CP=sm['carParams'], not_run=ignore)
started_prev = False

print_timer = 0
while True:
  sm.update(1000)  # 更新消息，超时1秒
  
  started = sm['deviceState'].started  # 检测是否启动
  
  # 状态转换时的参数清理
  if started and not started_prev:
    params.clear_all(ParamKeyType.CLEAR_ON_ONROAD_TRANSITION)
  elif not started and started_prev:
    params.clear_all(ParamKeyType.CLEAR_ON_OFFROAD_TRANSITION)
  
  # 更新onroad参数
  if started != started_prev:
    write_onroad_params(started, params)
  
  started_prev = started
  
  # 确保进程运行
  ensure_running(managed_processes.values(), started, params=params, CP=sm['carParams'], not_run=ignore)
  
  # 打印进程状态（每5次循环）
  running = ' '.join("{}{}\u001b[0m".format("\u001b[32m" if p.proc.is_alive() else "\u001b[31m", p.name)
                     for p in managed_processes.values() if p.proc)
  if print_timer % 5 == 0:
    print(running)
  print_timer += 1
  
  # 发布managerState
  msg = messaging.new_message('managerState', valid=True)
  msg.managerState.processes = [p.get_process_state_msg() for p in managed_processes.values()]
  pm.send('managerState', msg)
  
  # 检查是否需要关闭
  shutdown = False
  for param in ("DoUninstall", "DoShutdown", "DoReboot"):
    if params.get_bool(param):
      shutdown = True
      params.put("LastManagerExitReason", f"{param} {datetime.datetime.now()}")
      cloudlog.warning(f"Shutting down manager - {param} set")
  
  if shutdown:
    break
```

**执行流程**：
1. **消息更新**：`sm.update(1000)` - 等待最多1秒获取新消息
2. **状态检测**：检查`deviceState.started`判断系统是否启动
3. **参数清理**：状态转换时清理相应参数
4. **进程管理**：`ensure_running()`确保进程按需运行
5. **状态发布**：发布`managerState`消息
6. **关闭检查**：检查是否需要关闭系统

#### 1.3.3 ensure_running函数

**文件**：`system/manager/process.py`

```python
def ensure_running(procs: list[Process], started: bool, params: Params, CP: car.CarParams, not_run: list[str]) -> None:
  for p in procs:
    # 检查是否应该运行
    should_run = p.should_run(started, params, CP) and p.name not in not_run
    
    if p.proc is not None:
      if not p.proc.is_alive():
        # 进程已死，需要重启
        cloudlog.event("process died", proc=p.name, daemon=p.daemon)
        p.proc = None
        p.start()
      elif not should_run:
        # 不应该运行，停止进程
        p.stop(block=False)
    else:
      if should_run:
        # 应该运行但未运行，启动进程
        p.start()
```

**关键逻辑**：
- 检查每个进程是否应该运行（根据`should_run`函数）
- 如果进程已死，自动重启
- 如果进程不应该运行，停止它
- 如果进程应该运行但未运行，启动它

### 1.4 进程启动流程

#### 1.4.1 进程类型

**PythonProcess**：
```python
class PythonProcess(Process):
  def start(self):
    import importlib
    mod = importlib.import_module(self.module)
    self.proc = multiprocessing.Process(target=mod.main, name=self.name)
    self.proc.start()
```

**NativeProcess**：
```python
class NativeProcess(Process):
  def start(self):
    self.proc = subprocess.Popen(self.executable, cwd=self.cwd)
```

#### 1.4.2 进程启动顺序

1. **always_run进程**：立即启动
   - `logmessaged`：日志消息处理
   - `ui`：用户界面
   - `hardwared`：硬件管理
   - `pandad`：Panda设备通信

2. **onroad进程**：系统启动后启动
   - `camerad`：摄像头
   - `modeld`：模型推理
   - `controlsd`：控制决策
   - `card`：车辆接口
   - `plannerd`：路径规划

3. **条件启动进程**：
   - 根据车辆参数、硬件配置等决定

### 1.5 启动流程总结

**完整执行序列**：
1. `launch_openpilot.sh` → 启动脚本
2. `manager.py:main()` → 主入口
3. `manager_init()` → 初始化系统
   - 参数清理和设置
   - 设备注册
   - 日志初始化
4. `manager_thread()` → 主循环
   - 检测系统状态
   - 管理进程生命周期
   - 发布系统状态
5. `ensure_running()` → 确保进程运行
   - 检查进程状态
   - 启动/停止进程
6. 各进程`main()` → 进程启动
   - 初始化各自模块
   - 进入各自主循环

### 2.2 控制循环主流程

#### 2.2.1 controlsd_thread

```python
def controlsd_thread(self):
  e = threading.Event()
  t = threading.Thread(target=self.params_thread, args=(e,))
  try:
    t.start()  # 启动参数更新线程
    while True:
      self.step()  # 执行一步控制
      self.rk.monitor_time()  # 监控时间
  finally:
    e.set()
    t.join()
```

**执行流程**：
1. 启动参数更新线程（后台更新参数）
2. 进入主循环：`step()` → `monitor_time()`
3. 循环频率：100Hz（每10ms执行一次）

#### 2.2.2 step函数完整流程

```python
def step(self):
  start_time = time.monotonic()
  
  # 1. 数据采样
  CS = self.data_sample()
  cloudlog.timestamp("Data sampled")
  
  # 2. 事件更新
  self.update_events(CS)
  cloudlog.timestamp("Events updated")
  
  # 3. 状态转换（如果已初始化且非被动模式）
  if not self.CP.passive and self.initialized:
    self.state_transition(CS)
  
  # 4. 控制计算
  CC, lac_log = self.state_control(CS)
  
  # 5. 发布日志和控制命令
  self.publish_logs(CS, start_time, CC, lac_log)
  
  # 6. 保存当前状态
  self.CS_prev = CS
```

**执行顺序**：
1. **数据采样**：从消息队列获取最新数据
2. **事件更新**：根据数据生成事件
3. **状态转换**：根据事件更新状态机
4. **控制计算**：计算控制命令
5. **发布日志**：发布状态和控制命令
6. **状态保存**：保存当前状态供下次使用

### 2.3 数据采样详细流程

#### 2.3.1 data_sample函数

```python
def data_sample(self):
  # 接收carState消息
  car_state = messaging.recv_one(self.car_state_sock)
  CS = car_state.carState if car_state else self.CS_prev
  
  # 更新SubMaster中的所有消息
  self.sm.update(0)
  
  # 检查初始化状态
  if not self.initialized:
    all_valid = CS.canValid and self.sm.all_checks()
    timed_out = self.sm.frame * DT_CTRL > 6.
    
    if all_valid or timed_out or (SIMULATION and not REPLAY):
      # 检查摄像头流可用性
      available_streams = VisionIpcClient.available_streams("camerad", block=False)
      if VisionStreamType.VISION_STREAM_ROAD not in available_streams:
        self.sm.ignore_alive.append('roadCameraState')
      if VisionStreamType.VISION_STREAM_WIDE_ROAD not in available_streams:
        self.sm.ignore_alive.append('wideRoadCameraState')
      
      # 标记为已初始化
      self.initialized = True
      self.set_initial_state()
      
      cloudlog.event("controlsd.initialized", ...)
  
  # 处理controls_allowed不匹配
  if not self.enabled:
    self.mismatch_counter = 0
  
  if self.enabled and any(not ps.controlsAllowed for ps in self.sm['pandaStates']
         if ps.safetyModel not in IGNORED_SAFETY_MODES):
    self.mismatch_counter += 1
  
  return CS
```

**关键逻辑**：
1. **接收carState**：从card模块获取车辆状态
2. **更新消息**：更新所有订阅的消息
3. **初始化检查**：
   - 等待所有消息有效或超时（6秒）
   - 检查摄像头流可用性
   - 设置初始化标志
4. **安全检查**：检查controls_allowed是否匹配

### 2.4 事件更新详细流程

#### 2.4.1 update_events函数

```python
def update_events(self, CS):
  self.events.clear()  # 清空事件
  
  # 添加joystick事件
  if self.joystick_mode:
    self.events.add(EventName.joystickDebug)
  
  # 添加启动事件
  if self.startup_event is not None:
    self.events.add(self.startup_event)
    self.startup_event = None
  
  # 如果未初始化，只添加初始化事件
  if not self.initialized:
    self.events.add(EventName.controlsInitializing)
    return
  
  # 被动模式不添加事件
  if self.CP.passive:
    return
  
  # 添加驾驶员监控事件
  if not self.CP.notCar and not self.d_camera_hardware_missing:
    self.events.add_from_msg(self.sm['driverMonitoringState'].events)
  
  # 添加车辆事件
  if CS.canValid:
    self.events.add_from_msg(CS.events)
  
  # 添加系统状态事件
  if self.sm['deviceState'].thermalStatus >= ThermalStatus.red:
    self.events.add(EventName.overheat)
  if self.sm['deviceState'].freeSpacePercent < 7:
    self.events.add(EventName.outOfSpace)
  if self.sm['deviceState'].memoryUsagePercent > 90:
    self.events.add(EventName.lowMemory)
  
  # 添加校准状态事件
  cal_status = self.sm['liveCalibration'].calStatus
  if cal_status != log.LiveCalibrationData.Status.calibrated:
    if cal_status == log.LiveCalibrationData.Status.uncalibrated:
      self.events.add(EventName.calibrationIncomplete)
    elif cal_status == log.LiveCalibrationData.Status.recalibrating:
      self.events.add(EventName.calibrationRecalibrating)
  
  # 添加硬件故障事件
  if not self.sm.all_alive(self.camera_packets):
    self.events.add(EventName.cameraMalfunction)
  if not self.sm.all_checks(['radarState']):
    self.events.add(EventName.radarFault)
  if not self.sm.valid['pandaStates']:
    self.events.add(EventName.usbError)
  if CS.canTimeout:
    self.events.add(EventName.canBusMissing)
  elif not CS.canValid:
    self.events.add(EventName.canError)
  
  # ... 更多事件检查 ...
```

**事件类型**：
- **NO_ENTRY**：禁止进入（系统不可用）
- **SOFT_DISABLE**：软禁用
- **IMMEDIATE_DISABLE**：立即禁用
- **USER_DISABLE**：用户禁用
- **PRE_ENABLE**：预启用
- **ENABLE**：启用
- **WARNING**：警告

### 2.5 状态转换详细流程

#### 2.5.1 state_transition函数

```python
def state_transition(self, CS):
  # 更新巡航速度
  self.v_cruise_helper.v_cruise_kph = CS.exState.vCruiseKph
  
  # 递减软禁用计时器
  self.soft_disable_timer = max(0, self.soft_disable_timer - 1)
  
  self.current_alert_types = [ET.PERMANENT]
  
  # 非禁用状态的处理
  if self.state != State.disabled:
    # 用户禁用和立即禁用优先
    if self.events.contains(ET.USER_DISABLE):
      self.state = State.disabled
      self.current_alert_types.append(ET.USER_DISABLE)
    elif self.events.contains(ET.IMMEDIATE_DISABLE):
      self.state = State.disabled
      self.current_alert_types.append(ET.IMMEDIATE_DISABLE)
    else:
      # ENABLED状态
      if self.state == State.enabled:
        if self.events.contains(ET.SOFT_DISABLE):
          self.state = State.softDisabling
          self.soft_disable_timer = int(SOFT_DISABLE_TIME / DT_CTRL)
          self.current_alert_types.append(ET.SOFT_DISABLE)
        elif self.events.contains(ET.OVERRIDE_LATERAL) or self.events.contains(ET.OVERRIDE_LONGITUDINAL):
          self.state = State.overriding
          self.current_alert_types += [ET.OVERRIDE_LATERAL, ET.OVERRIDE_LONGITUDINAL]
      
      # SOFT_DISABLING状态
      elif self.state == State.softDisabling:
        if not self.events.contains(ET.SOFT_DISABLE):
          self.state = State.enabled
        elif self.soft_disable_timer <= 0:
          self.state = State.disabled
      
      # PRE_ENABLING状态
      elif self.state == State.preEnabled:
        if not self.events.contains(ET.PRE_ENABLE):
          self.state = State.enabled
      
      # OVERRIDING状态
      elif self.state == State.overriding:
        if self.events.contains(ET.SOFT_DISABLE):
          self.state = State.softDisabling
          self.soft_disable_timer = int(SOFT_DISABLE_TIME / DT_CTRL)
        elif not (self.events.contains(ET.OVERRIDE_LATERAL) or self.events.contains(ET.OVERRIDE_LONGITUDINAL)):
          self.state = State.enabled
  
  # DISABLED状态
  elif self.state == State.disabled:
    if self.events.contains(ET.ENABLE):
      if self.events.contains(ET.NO_ENTRY):
        self.current_alert_types.append(ET.NO_ENTRY)
      else:
        if self.events.contains(ET.PRE_ENABLE):
          self.state = State.preEnabled
        elif self.events.contains(ET.OVERRIDE_LATERAL) or self.events.contains(ET.OVERRIDE_LONGITUDINAL):
          self.state = State.overriding
        else:
          self.state = State.enabled
        self.current_alert_types.append(ET.ENABLE)
        self.v_cruise_helper.initialize_v_cruise(CS, self.experimental_mode)
  
  # 更新enabled和active标志
  self.enabled = self.state in ENABLED_STATES
  self.active = self.state in ACTIVE_STATES
  if self.active:
    self.current_alert_types.append(ET.WARNING)
```

**状态转换图**：
```
disabled → preEnabled → enabled
           ↓
      softDisabling → disabled
           ↓
      overriding → enabled
```

**关键转换**：
- `disabled` → `enabled`：收到ENABLE事件且无NO_ENTRY事件
- `enabled` → `softDisabling`：收到SOFT_DISABLE事件（给用户3秒接管）
- `softDisabling` → `disabled`：计时器到期或事件消失
- `enabled` → `overriding`：用户覆盖控制

def state_control(self, CS):
  # 1. 更新车辆模型参数
  lp = self.sm['liveParameters']
  x = max(lp.stiffnessFactor, 0.1)
  sr = max(lp.steerRatio, 0.1)
  self.VM.update_params(x, sr)
  
  # 2. 更新扭矩参数（如果使用扭矩控制）
  if self.CP.lateralTuning.which() == 'torque':
    torque_params = self.sm['liveTorqueParameters']
    if self.sm.all_checks(['liveTorqueParameters']) and torque_params.useParams:

        torque_params.latAccelFactorFiltered,
        torque_params.latAccelOffsetFiltered,
        torque_params.frictionCoefficientFiltered
      )
  
  # 3. 获取规划数据
  long_plan = self.sm['longitudinalPlan']
  model_v2 = self.sm['modelV2']
  
  # 4. 创建控制消息
  CC = car.CarControl.new_message()
  CC.enabled = self.enabled
  
  # 5. 检查执行器是否可以启用
  standstill = CS.vEgo <= max(self.CP.minSteerSpeed, MIN_LATERAL_CONTROL_SPEED) or CS.standstill
  CC.latActive = self.active and not CS.steerFaultTemporary and not CS.steerFaultPermanent and \
                 (not standstill or self.joystick_mode)
  CC.longActive = self.enabled and not self.events.contains(ET.OVERRIDE_LONGITUDINAL) and \
                  self.CP.openpilotLongitudinalControl
  
  actuators = CC.actuators
  actuators.longControlState = self.LoC.long_control_state
  
  # 6. 处理转向灯（车道变更时）
  if model_v2.meta.laneChangeState != LaneChangeState.off:
    CC.leftBlinker = model_v2.meta.laneChangeDirection == LaneChangeDirection.left
    CC.rightBlinker = model_v2.meta.laneChangeDirection == LaneChangeDirection.right
  
  # 7. 状态特定操作
  if not CC.latActive:
    self.LaC.reset()  # 重置横向控制
  if not CC.longActive:
    self.LoC.reset()  # 重置纵向控制
  
  # 8. 计算纵向控制
  if not self.joystick_mode:
    pid_accel_limits = self.CI.get_pid_accel_limits(

    )
    actuators.accel = self.LoC.update(
      CC.longActive, CS, long_plan.aTarget, long_plan.shouldStop, pid_accel_limits

      CS.vEgo, self.desired_curvature, model_v2.action.desiredCurvature

      CC.latActive, CS, self.VM, lp, self.steer_limited, 
      self.desired_curvature, self.sm['liveLocationKalman']
    )
  else:
    # Joystick模式
    # ... joystick控制逻辑 ...
  
  # 10. 检查转向饱和
  if lac_log.active and not recent_steer_pressed and not self.CP.notCar:
    if self.CP.lateralTuning.which() == 'torque' and not self.joystick_mode:
      # 扭矩控制饱和检查
      undershooting = abs(lac_log.desiredLateralAccel) / abs(1e-3 + lac_log.actualLateralAccel) > 1.2
      turning = abs(lac_log.desiredLateralAccel) > 1.0
      good_speed = CS.vEgo > 5
      max_torque = abs(self.sm['carOutput'].actuatorsOutput.steer) > 0.99
      if undershooting and turning and good_speed and max_torque:
        self.events.add(EventName.steerSaturated)
    elif lac_log.saturated:
      # 检查是否偏离路径
      dpath_points = model_v2.position.y
      if len(dpath_points):
        if self.CP.steerControlType == car.CarParams.SteerControlType.angle:
          steering_value = actuators.steeringAngleDeg
        else:
          steering_value = actuators.steer
        
        left_deviation = steering_value > 0 and dpath_points[0] < -0.20
        right_deviation = steering_value < 0 and dpath_points[0] > 0.20
        
        if left_deviation or right_deviation:
          self.events.add(EventName.steerSaturated)
  
  # 11. 验证控制值（确保非NaN/Inf）
  for p in ACTUATOR_FIELDS:
    attr = getattr(actuators, p)
    if not isinstance(attr, SupportsFloat):
      continue
    if not math.isfinite(attr):
      cloudlog.error(f"actuators.{p} not finite {actuators.to_dict()}")
      setattr(actuators, p, 0.0)
  
  return CC, lac_log

```python
def update(self, active, CS, a_target, should_stop, accel_limits):
  # 设置PID限制
  self.pid.neg_limit = accel_limits[0]
  self.pid.pos_limit = accel_limits[1]
  
  # 状态转换
  self.long_control_state = long_control_state_trans(
    self.CP, active, self.long_control_state, CS.vEgo,
    should_stop, CS.brakePressed, CS.cruiseState.standstill
  )
  
  # 根据状态计算输出
  if self.long_control_state == LongCtrlState.off:
    self.reset()
    output_accel = 0.
  elif self.long_control_state == LongCtrlState.stopping:
    # 停止状态：逐渐减小加速度
    output_accel = self.last_output_accel
    if output_accel > self.CP.stopAccel:
      output_accel = min(output_accel, 0.0)
      output_accel -= self.CP.stoppingDecelRate * DT_CTRL
    self.reset()
  elif self.long_control_state == LongCtrlState.starting:
    # 启动状态：使用固定加速度
    output_accel = self.CP.startAccel
    self.reset()
  else:  # LongCtrlState.pid
    # PID控制状态
    error = a_target - CS.aEgo
    output_accel = self.pid.update(error, speed=CS.vEgo, feedforward=a_target)
  
  # 限制输出
  self.last_output_accel = clip(output_accel, accel_limits[0], accel_limits[1])
  return self.last_output_accel
```

**状态机**：
- `off`：关闭，输出0
- `stopping`：停止中，逐渐减小加速度
- `starting`：启动中，使用固定加速度
- `pid`：PID控制，跟踪目标加速度

```python
def update(self, active, CS, VM, params, steer_limited, desired_curvature, llk):
  pid_log = log.ControlsState.LateralPIDState.new_message()
  
  # 计算期望转向角
  angle_steers_des_no_offset = math.degrees(
    VM.get_steer_from_curvature(-desired_curvature, CS.vEgo, params.roll)
  )
  angle_steers_des = angle_steers_des_no_offset + params.angleOffsetDeg
  error = angle_steers_des - CS.steeringAngleDeg
  
  if not active:
    output_steer = 0.0
    self.pid.reset()
  else:
    # 计算前馈
    steer_feedforward = self.get_steer_feedforward(angle_steers_des_no_offset, CS.vEgo)
    
    # PID控制
    output_steer = self.pid.update(
      error, 
      override=CS.steeringPressed,
      feedforward=steer_feedforward, 
      speed=CS.vEgo
    )
  
  # 检查饱和
  pid_log.saturated = self._check_saturation(
    self.steer_max - abs(output_steer) < 1e-3, CS, steer_limited
  )
  
  return output_steer, angle_steers_des, pid_log
```

**计算流程**：
1. 从期望曲率计算期望转向角
2. 计算误差（期望 - 当前）
3. 计算前馈（基于速度和角度）
4. PID控制计算输出
5. 检查饱和

```python
def run(self, buf: VisionBuf, wbuf: VisionBuf, transform: np.ndarray, transform_wide: np.ndarray,
        inputs: dict[str, np.ndarray], prepare_only: bool) -> dict[str, np.ndarray] | None:
  # 处理期望动作（脉冲触发）
  inputs['desire'][0] = 0
  self.inputs['desire'][:-ModelConstants.DESIRE_LEN] = self.inputs['desire'][ModelConstants.DESIRE_LEN:]
  self.inputs['desire'][-ModelConstants.DESIRE_LEN:] = np.where(
    inputs['desire'] - self.prev_desire > .99, inputs['desire'], 0
  )
  self.prev_desire[:] = inputs['desire']
  
  # 更新其他输入
  self.inputs['traffic_convention'][:] = inputs['traffic_convention']
  self.inputs['lateral_control_params'][:] = inputs['lateral_control_params']
  
  # 准备图像输入
  self.model.setInputBuffer("input_imgs", 
    self.frame.prepare(buf, transform.flatten(), self.model.getCLBuffer("input_imgs"))
  )
  if wbuf is not None:
    self.model.setInputBuffer("big_input_imgs", 
      self.wide_frame.prepare(wbuf, transform_wide.flatten(), self.model.getCLBuffer("big_input_imgs"))
    )
  
  # 如果只是准备（掉帧情况），不执行推理
  if prepare_only:
    return None
  
  # 执行模型推理
  self.model.execute()
  
  # 解析输出
  outputs = self.parser.parse_outputs(self.slice_outputs(self.output))
  
  # 更新历史状态
  self.inputs['features_buffer'][:-ModelConstants.FEATURE_LEN] = \
    self.inputs['features_buffer'][ModelConstants.FEATURE_LEN:]
  self.inputs['features_buffer'][-ModelConstants.FEATURE_LEN:] = outputs['hidden_state'][0, :]
  
  self.inputs['prev_desired_curv'][:-ModelConstants.PREV_DESIRED_CURV_LEN] = \
    self.inputs['prev_desired_curv'][ModelConstants.PREV_DESIRED_CURV_LEN:]
  self.inputs['prev_desired_curv'][-ModelConstants.PREV_DESIRED_CURV_LEN:] = \
    outputs['desired_curvature'][0, :]
  
  return outputs
```

```python
def parse_outputs(self, outs: dict[str, np.ndarray]) -> dict[str, np.ndarray]:
  # 解析路径规划（MDN）
  self.parse_mdn('plan', outs, 
    in_N=ModelConstants.PLAN_MHP_N, 
    out_N=ModelConstants.PLAN_MHP_SELECTION,
    out_shape=(ModelConstants.IDX_N, ModelConstants.PLAN_WIDTH)
  )
  
  # 解析车道线（MDN）
  self.parse_mdn('lane_lines', outs, 
    in_N=0, out_N=0, 
    out_shape=(ModelConstants.NUM_LANE_LINES, ModelConstants.IDX_N, ModelConstants.LANE_LINES_WIDTH)
  )
  
  # 解析道路边缘（MDN）
  self.parse_mdn('road_edges', outs, 
    in_N=0, out_N=0, 
    out_shape=(ModelConstants.NUM_ROAD_EDGES, ModelConstants.IDX_N, ModelConstants.LANE_LINES_WIDTH)
  )
  
  # 解析姿态（MDN）
  self.parse_mdn('pose', outs, in_N=0, out_N=0, out_shape=(ModelConstants.POSE_WIDTH,))
  
  # 解析前车（MDN）
  self.parse_mdn('lead', outs, 
    in_N=ModelConstants.LEAD_MHP_N, 
    out_N=ModelConstants.LEAD_MHP_SELECTION,
    out_shape=(ModelConstants.LEAD_TRAJ_LEN, ModelConstants.LEAD_WIDTH)
  )
  
  # 解析期望曲率（MDN）
  if 'desired_curvature' in outs:
    self.parse_mdn('desired_curvature', outs, in_N=0, out_N=0, out_shape=(ModelConstants.DESIRED_CURV_WIDTH,))
  
  # 解析概率输出（二分类）
  for k in ['lead_prob', 'lane_lines_prob', 'meta']:
    self.parse_binary_crossentropy(k, outs)
  
  # 解析期望状态（分类）
  self.parse_categorical_crossentropy('desire_state', outs)
  
  return outs
```

**解析类型**：
- **MDN（混合密度网络）**：用于路径、车道线等，输出多个假设
- **二分类**：使用sigmoid，用于概率输出
- **多分类**：使用softmax，用于期望状态

#### 3.4.2 MDN解析详细过程

```python
def parse_mdn(self, name, outs, in_N=0, out_N=1, out_shape=None):
  raw = outs[name]
  raw = raw.reshape((raw.shape[0], max(in_N, 1), -1))
  
  # 分离均值和标准差
  n_values = (raw.shape[2] - out_N) // 2
  pred_mu = raw[:,:,:n_values]  # 均值
  pred_std = np.exp(raw[:,:,n_values: 2*n_values])  # 标准差（exp确保为正）
  
  if in_N > 1:
    # 多个假设，需要计算权重
    weights = np.zeros((raw.shape[0], in_N, out_N), dtype=raw.dtype)
    for i in range(out_N):
      weights[:,:,i - out_N] = softmax(raw[:,:,i - out_N], axis=-1)
    
    # 选择最佳假设
    if out_N == 1:
      for fidx in range(weights.shape[0]):
        idxs = np.argsort(weights[fidx][:,0])[::-1]
        weights[fidx] = weights[fidx][idxs]
        pred_mu[fidx] = pred_mu[fidx][idxs]
        pred_std[fidx] = pred_std[fidx][idxs]
    
    # 选择权重最高的假设
    pred_mu_final = np.zeros((raw.shape[0], out_N, n_values), dtype=raw.dtype)
    pred_std_final = np.zeros((raw.shape[0], out_N, n_values), dtype=raw.dtype)
    for fidx in range(weights.shape[0]):
      for hidx in range(out_N):
        idxs = np.argsort(weights[fidx,:,hidx])[::-1]
        pred_mu_final[fidx, hidx] = pred_mu[fidx, idxs[0]]
        pred_std_final[fidx, hidx] = pred_std[fidx, idxs[0]]
  else:
    pred_mu_final = pred_mu
    pred_std_final = pred_std
  
  # 重塑输出
  if out_N > 1:
    final_shape = tuple([raw.shape[0], out_N] + list(out_shape))
  else:
    final_shape = tuple([raw.shape[0],] + list(out_shape))
  
  outs[name] = pred_mu_final.reshape(final_shape)
  outs[name + '_stds'] = pred_std_final.reshape(final_shape)
```

**MDN解析步骤**：
1. 重塑原始输出
2. 分离均值和标准差
3. 如果有多个假设，计算权重（softmax）
4. 选择权重最高的假设
5. 重塑为最终形状
