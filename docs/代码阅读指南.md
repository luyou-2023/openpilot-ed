# OpenPilot 代码阅读指南

## 1. 代码结构概览

### 1.1 目录结构

```
openpilot/
├── system/              # 系统层模块
│   ├── manager/         # 进程管理器
│   ├── camerad/         # 摄像头驱动
│   ├── loggerd/         # 日志记录
│   ├── locationd/       # 定位模块
│   └── hardware/        # 硬件抽象
├── selfdrive/           # 自动驾驶核心模块
│   ├── controls/        # 控制系统
│   ├── modeld/          # 模型推理
│   ├── car/             # 车辆接口
│   ├── monitoring/      # 监控模块
│   └── ui/              # 用户界面
├── common/              # 通用工具库
├── cereal/             # 消息定义（Cap'n Proto）
└── tools/               # 开发工具
```

### 1.2 关键文件位置

**入口点**：
- `system/manager/manager.py`：系统主入口
- `launch_openpilot.sh`：启动脚本

**核心模块**：
- `selfdrive/controls/controlsd.py`：控制决策
- `selfdrive/modeld/modeld.py`：模型推理
- `selfdrive/car/card.py`：车辆接口
- `selfdrive/controls/plannerd.py`：路径规划

## 2. 代码阅读路径

### 2.1 系统启动流程

**阅读顺序**：
1. `launch_openpilot.sh` → 启动脚本
2. `system/manager/manager.py` → 主进程
   - `manager_init()` → 初始化
   - `manager_thread()` → 主循环
3. `system/manager/process_config.py` → 进程配置
4. `system/manager/process.py` → 进程管理

**关键代码**：
```python
# manager.py
def main():
    manager_init()
    manager_thread()  # 主循环
```

### 2.2 控制流程

**阅读顺序**：
1. `selfdrive/controls/controlsd.py` → 控制主模块
   - `Controls.__init__()` → 初始化
   - `Controls.step()` → 主循环
2. `selfdrive/controls/lib/longcontrol.py` → 纵向控制
3. `selfdrive/controls/lib/latcontrol.py` → 横向控制基类
4. `selfdrive/controls/lib/latcontrol_pid.py` → PID横向控制
5. `selfdrive/controls/lib/latcontrol_torque.py` → 扭矩横向控制

**关键代码**：
```python
# controlsd.py
def step(self):
    CS = self.data_sample()        # 数据采样
    self.update_events(CS)         # 事件更新
    self.state_transition(CS)      # 状态转换
    CC, lac_log = self.state_control(CS)  # 控制计算
    self.publish_logs(CS, start_time, CC, lac_log)  # 发布
```

### 2.3 模型推理流程

**阅读顺序**：
1. `selfdrive/modeld/modeld.py` → 模型主模块
   - `ModelState.__init__()` → 模型初始化
   - `ModelState.run()` → 推理执行
2. `selfdrive/modeld/runners/` → 模型运行器
3. `selfdrive/modeld/parse_model_outputs.py` → 输出解析
4. `selfdrive/modeld/fill_model_msg.py` → 消息填充

**关键代码**：
```python
# modeld.py
def main():
    model = ModelState(cl_context)  # 初始化模型
    while True:
        buf_main = vipc_client_main.recv()  # 接收图像
        model_output = model.run(...)  # 执行推理
        fill_model_msg(...)  # 填充消息
```

### 2.4 车辆接口流程

**阅读顺序**：
1. `selfdrive/car/card.py` → 车辆接口主模块
   - `Car.__init__()` → 车辆识别
   - `Car.step()` → 主循环
2. `selfdrive/car/interfaces.py` → 接口基类
3. `selfdrive/car/{brand}/interface.py` → 品牌特定实现
4. `selfdrive/car/{brand}/carstate.py` → 状态解析
5. `selfdrive/car/{brand}/carcontroller.py` → 控制命令生成

**关键代码**：
```python
# card.py
def step(self):
    CS = self.state_update()      # 更新状态
    self.update_events(CS)        # 更新事件
    self.state_publish(CS)        # 发布状态
    self.controls_update(CS, CC)  # 发送控制
```

## 3. 关键概念理解

### 3.1 消息系统

**Cap'n Proto消息**：
- 定义在`cereal/`目录
- 使用`.capnp`文件定义
- 通过`messaging`模块使用

**使用示例**：
```python
# 发布消息
pm = messaging.PubMaster(['carState'])
msg = messaging.new_message('carState')
msg.carState = CS
pm.send('carState', msg)

# 订阅消息
sm = messaging.SubMaster(['carControl', 'modelV2'])
sm.update()
CC = sm['carControl']
```

### 3.2 状态机

**Controls状态机**：
- `disabled`：禁用
- `preEnabled`：预启用
- `enabled`：启用
- `softDisabling`：软禁用中
- `overriding`：覆盖控制

**状态转换**：
```python
# controlsd.py
def state_transition(self, CS):
    if self.state == State.disabled:
        if self.events.contains(ET.ENABLE):
            self.state = State.enabled
    elif self.state == State.enabled:
        if self.events.contains(ET.SOFT_DISABLE):
            self.state = State.softDisabling
```

### 3.3 控制算法

**PID控制**：
```python
# latcontrol_pid.py
error = angle_steers_des - CS.steeringAngleDeg
output_steer = self.pid.update(error, feedforward=steer_feedforward)
```

**MPC控制**：
```python
# long_mpc.py
self.mpc.update(sm, v_cruise, x, v, a, j)
```

### 3.4 CAN通信

**CAN消息格式**：
```python
SendCan = tuple[int, bytes, int]  # (address, data, bus)
```

**消息发送**：
```python
# card.py
can_sends = self.CI.apply(CC, now_nanos)
self.pm.send('sendcan', can_list_to_can_capnp(can_sends))
```

## 5. 常见问题

### 5.1 如何添加新车型？

1. 创建车型目录：`selfdrive/car/newbrand/`
2. 实现接口：
   - `interface.py`：实现`CarInterface`
   - `carstate.py`：实现`CarState`
   - `carcontroller.py`：实现`CarController`
3. 定义参数：`values.py`
4. 定义指纹：`fingerprints.py`
5. 注册到`interfaces.py`

### 5.2 如何修改控制算法？

**修改横向控制**：
- 编辑`selfdrive/controls/lib/latcontrol_*.py`
- 或创建新的控制类

**修改纵向控制**：
- 编辑`selfdrive/controls/lib/longcontrol.py`
- 或修改MPC参数

### 5.3 如何添加新功能？

1. 定义消息类型（如果需要）：`cereal/*.capnp`
2. 实现功能模块
3. 在`process_config.py`注册进程
4. 通过消息系统通信

## 6. 代码规范

### 6.1 命名规范

- **类名**：大驼峰（`CarInterface`）
- **函数名**：小写下划线（`update_state`）
- **常量**：大写下划线（`MAX_SPEED`）
- **私有方法**：下划线前缀（`_internal_method`）

### 6.2 注释规范

**文档字符串**：
```python
def update(self, CS, CC):
    """
    更新车辆状态
    
    Args:
        CS: 车辆状态
        CC: 控制命令
    
    Returns:
        更新后的车辆状态
    """
```

**行内注释**：
```python
# 计算期望转向角
angle_steers_des = math.degrees(VM.get_steer_from_curvature(...))
```

### 6.3 错误处理

**异常捕获**：
```python
try:
    # 代码
except Exception as e:
```
