# OpenPilot 架构与时序图文档

## 文档说明

本文档从多个视角展示OpenPilot系统的架构图和时序图：
1. **架构图**：框架架构、模块架构、消息驱动架构、任务调度架构
2. **时序图**：系统启动、控制循环、模型推理、CAN消息处理等关键功能的时序

## 第二部分：时序图

### 2.1 系统启动时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Manager as manager
    participant Params as Params
    participant Camerad as camerad
    participant Pandad as pandad
    participant Card as card
    participant Modeld as modeld
    participant Plannerd as plannerd
    participant Controlsd as controlsd
    
    User->>Manager: 启动系统
    Manager->>Manager: manager_init()
    Manager->>Params: 清理参数
    Manager->>Params: 设置默认参数
    Manager->>Manager: 设备注册
    
    Manager->>Manager: manager_thread()
    Manager->>Manager: 检测deviceState.started
    
    alt started == True
        Manager->>Camerad: 启动进程
        Manager->>Pandad: 启动进程
        Manager->>Card: 启动进程
        Manager->>Modeld: 启动进程
        Manager->>Plannerd: 启动进程
        Manager->>Controlsd: 启动进程
        
        Camerad->>Camerad: 初始化摄像头
        Pandad->>Pandad: 初始化Panda
        Card->>Card: 等待CAN消息
        Card->>Card: 识别车辆
        Card->>Card: 发布carParams
        
        Modeld->>Modeld: 加载模型
        Modeld->>Modeld: 初始化GPU
        Plannerd->>Plannerd: 初始化MPC
        Controlsd->>Controlsd: 初始化状态机
        
        Note over Manager,Controlsd: 系统就绪，开始控制循环
    else started == False
        Manager->>Manager: 停止所有进程
    end
```

**启动流程说明**：
1. **初始化阶段**：参数清理、设备注册
2. **进程启动**：根据状态启动/停止进程
3. **模块初始化**：各模块完成自身初始化
4. **系统就绪**：所有模块就绪后开始控制循环

### 2.2 控制循环时序图（消息驱动）

```mermaid
sequenceDiagram
    participant Camerad as camerad<br/>20Hz
    participant Modeld as modeld<br/>20Hz
    participant Card as card<br/>100Hz
    participant Plannerd as plannerd<br/>20Hz
    participant Controlsd as controlsd<br/>100Hz
    participant Pandad as pandad<br/>100Hz
    participant ECU as 车辆ECU
    
    Note over Camerad,ECU: 控制循环（100Hz，10ms周期）
    
    loop 每10ms
        Card->>Card: 接收CAN消息
        Card->>Card: 解析carState
        Card-->>Controlsd: 发布carState
        
        Controlsd->>Controlsd: 订阅carState
        Controlsd->>Controlsd: 更新状态机
        
        alt 每50ms (modeld周期)
            Camerad->>Camerad: 采集图像
            Camerad-->>Modeld: 发布roadCameraState
            
            Modeld->>Modeld: 订阅roadCameraState
            Modeld->>Modeld: 订阅carState
            Modeld->>Modeld: 预处理图像
            Modeld->>Modeld: 模型推理(GPU)
            Modeld->>Modeld: 解析输出
            Modeld-->>Plannerd: 发布modelV2
            Modeld-->>Controlsd: 发布modelV2
            
            Plannerd->>Plannerd: 订阅modelV2
            Plannerd->>Plannerd: 订阅carState
            Plannerd->>Plannerd: MPC优化
            Plannerd-->>Controlsd: 发布longitudinalPlan
        end
        
        Controlsd->>Controlsd: 订阅modelV2
        Controlsd->>Controlsd: 订阅longitudinalPlan
        Controlsd->>Controlsd: 订阅radarState
        Controlsd->>Controlsd: 计算控制命令
        Controlsd->>Controlsd: PID/MPC控制
        Controlsd-->>Card: 发布carControl
        
        Card->>Card: 订阅carControl
        Card->>Card: 转换为CAN消息
        Card-->>Pandad: 发布sendcan
        
        Pandad->>Pandad: 订阅sendcan
        Pandad->>Pandad: 硬件安全检查
        Pandad->>ECU: 发送CAN消息
        
        ECU->>ECU: 执行控制命令
        ECU->>ECU: 车辆转向/加速
    end
```

**控制循环说明**：
- **100Hz主循环**：controlsd和card以100Hz运行
- **20Hz感知循环**：modeld和plannerd以20Hz运行
- **消息驱动**：所有模块通过消息队列通信
- **实时保证**：高优先级保证控制及时性

### 2.4 CAN消息处理时序图

```mermaid
sequenceDiagram
    participant ECU as 车辆ECU
    participant CAN as CAN总线
    participant Pandad as pandad
    participant Card as card
    participant Controlsd as controlsd
    participant CarInterface as CarInterface
    
    Note over ECU,CarInterface: CAN消息处理（100Hz）
    
    loop 接收CAN消息
        ECU->>CAN: 发送CAN消息
        CAN->>Pandad: 接收CAN消息
        Pandad->>Pandad: 转换为capnp格式
        Pandad-->>Card: 发布can消息
        
        Card->>Card: 订阅can消息
        Card->>CarInterface: 解析CAN消息
        CarInterface->>CarInterface: DBC解析
        CarInterface->>CarInterface: 提取车辆状态
        CarInterface-->>Card: 返回carState
        Card-->>Controlsd: 发布carState
    end
    
    Note over ECU,CarInterface: 控制命令发送
    
    loop 发送控制命令
        Controlsd->>Controlsd: 计算控制命令
        Controlsd-->>Card: 发布carControl
        
        Card->>Card: 订阅carControl
        Card->>CarInterface: 转换为CAN消息
        CarInterface->>CarInterface: 单位转换
        CarInterface->>CarInterface: 应用限制
        CarInterface->>CarInterface: DBC打包
        CarInterface-->>Card: 返回CAN消息列表
        
        Card-->>Pandad: 发布sendcan
        
        Pandad->>Pandad: 订阅sendcan
        Pandad->>Pandad: 硬件安全检查
        Pandad->>CAN: 发送CAN消息
        CAN->>ECU: 接收CAN消息
        ECU->>ECU: 验证消息
        ECU->>ECU: 执行控制命令
    end
```

**CAN消息处理说明**：
- **双向通信**：接收车辆状态，发送控制命令
- **DBC解析**：自动解析CAN消息格式
- **安全验证**：Panda硬件级安全检查
- **实时保证**：100Hz频率，保证控制及时性

### 2.5 状态机转换时序图

```mermaid
stateDiagram-v2
    [*] --> disabled: 系统启动
    
    disabled --> preEnabled: 用户按下启用按钮
    preEnabled --> disabled: 用户取消或超时
    
    preEnabled --> enabled: 满足启用条件<br/>(速度、位置等)
    
    enabled --> softDisabling: 用户操作<br/>(转向、制动、加速)
    enabled --> softDisabling: 系统检测异常
    
    softDisabling --> disabled: 车辆停止<br/>(3秒后)
    
    enabled --> overriding: 用户强制操作
    overriding --> disabled: 用户操作结束
    
    disabled --> [*]: 系统关闭
    
    note right of enabled
        控制激活
        发送控制命令
    end note
    
    note right of softDisabling
        平滑禁用
        给用户3秒接管时间
    end note
```

**状态机说明**：
- **disabled**：系统禁用，不发送控制命令
- **preEnabled**：准备启用，等待满足条件
- **enabled**：系统激活，发送控制命令
- **softDisabling**：软禁用，平滑过渡
- **overriding**：用户覆盖，系统禁用

```mermaid
        Controlsd->>Controlsd: 提取期望曲率
        
        Controlsd->>Controlsd: 曲率平滑
        Note over Controlsd: 限制曲率变化率<br/>速度相关限制
        
        alt PID控制模式
            Controlsd->>Controlsd: 曲率转角度
            Controlsd->>PID: 计算转向角
            PID->>PID: PID控制
            PID-->>Controlsd: 返回转向角
        else MPC控制模式
            Controlsd->>Controlsd: 提取路径点
            Controlsd->>MPC: 设置参考路径
            Controlsd->>MPC: 设置当前状态
            MPC->>MPC: 求解优化问题
            MPC-->>Controlsd: 返回转向角
        end
        
        Controlsd->>Controlsd: 应用限制
        Note over Controlsd: 转向角限制<br/>变化率限制
        
        Controlsd->>Controlsd: 填充carControl
        Controlsd-->>Card: 发布carControl
        
        Card->>Card: 订阅carControl
        Card->>Card: 转换为CAN消息
    end
```

**横向控制说明**：
- **端到端**：模型直接输出期望曲率
- **双模式**：PID或MPC控制
- **平滑处理**：限制曲率变化率
- **实时控制**：100Hz频率

## 第三部分：关键交互模式

### 3.1 消息驱动模式

**特点**：

- 解耦设计

- 模块独立开发

- 时间确定性

**优势**：
- 保证实时性
- 可预测性
- 资源隔离

### 3.3 混合模式

**实际系统**：
- 消息驱动：模块间通信
- 调度驱动：模块内执行
- 两者结合：保证实时性和解耦
